# CTS 波段 API 下單系統｜V0 安全核心（開發分支）
狀態：**PAPER_ONLY / LIVE_TRADING=DISABLED**。本分支不是正式交易版本；沒有玉山券商連線、憑證、正式委託、取消、成交回報或自動賣出功能。

## 對齊 CTS 方向
- 策略唯一權威：Notion CTS V5.2。1–3 週、3–7% 目標為研究假設，非保證報酬。
- 一次一檔主股；現有庫存及未成交委託須先由本機券商對帳，禁止憑 GitHub 公開資料推斷持股。
- AI 僅提出候選，規則引擎做風控；真實下單須獨立實作券商介面、測試及明確授權。
- GitHub 公開研究 `latest.json` 為研究用途，絕不單憑排名自動買進。
- 現況：2168 名錄僅 68 檔成功評估，覆蓋約 3.14%，低於暫定 95% 資料門檻，因此預設拒絕。
- 單筆 10,000、總額 30,000、日損 500 元均為**測試用占位值**，未經使用者核准，不可作為正式下單限額。

## 目前可驗證
在 `engine/` 執行 `python -m unittest -v test_swing_gate.py`。測試涵蓋資料覆蓋、重複訊號、已有持倉、券商對帳、NaN 價格、日損、未實作賣出與研究資料非交易授權。
安全核心目前對所有買單 fail-closed；不包含券商 SDK，不會發送網路請求。

## 進入正式 API 前必須完成
1. 取得玉山證券正式 API 文件及可用權限，僅在 Windows 本機保管憑證；不可提交公開 GitHub。
2. 訂定並核對 CTS V5.2 明確進出場訊號、價量來源、停損、獲利了結、持有期限、交易成本、零股/整股、價格跳動單位、漲跌停、盤中時段。
3. 實作券商介面：登入、查詢可用資金、持倉、未成交、下單、回報、取消/改單、重試冪等鍵、斷線復原；每步先模擬及故障注入測試。
4. 先回測與樣本外驗證，再 shadow mode、紙上交易、券商沙盒或無風險查詢驗證；最後另行授權小額實盤。
5. 正式交易啟用須雙重人工確認、獨立熔斷器及緊急停機。不得因 AI、Claude 或公開 GitHub 檔案自動啟用。
